# 수원 아이랑 이번 주 — 설계

작성일 2026-10-26. 브레인스토밍 대화에서 정한 것을 정리했다. "사용자 결정"은 사용자가 말한 것이고, "Claude 판단"은 대화에서 사용자에게 알렸지만 따로 동의를 받지 않은 기본값이다.

## 1. 왜 만드나

8세 이하 아이를 키우는 수원 부모는 행사 소식을 인스타·스레드에서 우연히 보고 알게 된다. 수원시·스타필드·경기도 행사 정보가 여러 곳에 흩어져 있어서, "이번 주에 애랑 갈 만한 데"를 한 화면에서 볼 수 없다.

이 앱은 **이번 주 수원에서 열리는 행사를 동네별로 한 화면에** 보여 준다. 첫 사용자는 사용자 본인 가족이고, 네이버 블로그 주간 글로 다른 수원 부모에게 알린다.

## 2. 목표 / 비목표 / 실패 기준

목표
- 이번 주(오늘~일요일) 수원에서 열리는 행사를 동네별로 보여 준다
- 데이터는 매일 자동으로 모은다. 사람이 손으로 입력하지 않는다
- 매주 블로그 글로 이번 주말 행사를 소개하고 앱 링크를 단다

비목표 (사용자 결정)
- 로그인, 후기, 댓글, 즐겨찾기 등 사용자 입력 기능 없음. 보기 전용
- 관광지·고정 장소 소개 없음 (예: 박물관 소개, 유모차 대여 정보). **열리는 일**만
- 유모차·주차·붐빔 같은 태그 없음 (시안에서 사용자가 빼라고 함)
- 인스타·아파트 단지·키즈카페 소식은 1차에 넣지 않는다. 써 보고 부족하면 추가
- 수원 밖 지역은 1차에 넣지 않는다. 다만 지역을 늘릴 수 있게 지역 단위로 데이터를 나눈다

실패 기준 (이렇게 되면 기능이 돌아가도 실패)
- 끝난 행사가 이번 주 행사처럼 보인다
- 수원시·경기도 주최 축제가 빠진다 (사용자: "무조건 보여야지")
- 강좌 수강생 모집, 경로잔치, 성인 전용 강연처럼 아이와 관계없는 항목이 화면을 채운다
- 확인 안 된 내용(출연자, 시간)을 AI가 지어낸다

## 3. 데이터 출처

모두 2026-10-26에 직접 호출해 응답을 확인했다 (경기도 API 제외).

| 출처 | 방법 | 확인한 내용 |
|---|---|---|
| 수원특례시 행사축제포털 | `GET https://www.suwon.go.kr/culture/smartSearchListJson.do?q_rowPerPage=200&q_currPage=N` (키·로그인 없음) | 전체 1,867건(과거 포함), 10페이지. 필드: `cultureNm`, `startDt`/`endDt`(`2026-10-09(금)` 형식), `startTime`/`endTime`, `ctrLocation`, `baseAddr`, `dongNm`, `ctrTarget`(대부분 "누구나"), `ctrLocationX/Y`, `ctrSeqNo`, `chargeYn`, `ticketPrice`, `thumbImage`. 상세: `ingCultureView.do?ctrSeqNo=N`(주최기관·행사내용 등). 목록 응답에는 주최기관(`ctrOrg`)이 비어 있음 |
| 스타필드 수원 | 1) `GET https://www.starfield.co.kr/suwon/eventBenefit/events`로 쿠키 받기 2) `GET https://www.starfield.co.kr/api/suwon/event/eventList.do?evt_gbn=event&lang=ko&pageIndex=1` (같은 쿠키·Referer). 쿠키 없으면 `data: []` | `evt_titl`, `evtStrtDtTxt`(예 `11.7(토), 11.14(토)…`), `evt_post_strt_dt`/`evt_post_end_dt`, `img_uri`(포스터). 프로그램별 시간·연령은 **포스터 이미지 안에만** 있음 |
| 경기아트센터 | `https://www.ggac.or.kr/` (200 응답 확인) | 공연 목록 수집 방법은 미확인. 시 포털에는 작년부터 1건만 있어 따로 모아야 함 |
| 경기문화재단 | `https://www.ggcf.kr/` (200 응답 확인) | 경기상상캠퍼스 등. 수집 방법 미확인 |
| 경기데이터드림 API | `openapi.gg.go.kr` | "보안 정책에 의해 차단" 응답. 쓰지 않는다 |

사용자가 예로 든 행사가 시 포털에 있는지 확인했다: 임창정·손승연 공연(제3회 문화도시 수원 페스티벌, 10.9~10, 대유평공원), 통닭거리 축제, 행궁동 프리마켓 〈조선달빛장〉, 수문장 마켓, 광교호수공원 드론·불꽃 축제·재즈페스티벌 모두 있음. 단, 포털 제목에 출연 가수 이름은 없다.

## 4. 처리 규칙

**기간**: 수집 시점 기준 오늘~이번 주 일요일에 하루라도 걸치는 행사만. 상설 전시처럼 몇 달짜리 행사는 "상시"로 따로 묶어 아래에 둔다 (Claude 판단).

**거르기** (Claude 판단, 사용자는 방향에 동의)
- `ctrTarget`에 "어린이" 또는 "누구나"가 없으면 뺀다
- 제목에 모집·수강생·경로·채용 등이 들어가면 뺀다
- **예외: 수원시·경기도가 주최하는 축제는 위 규칙과 상관없이 항상 남긴다** (사용자 결정). 주최기관은 상세 페이지의 "주최기관"에서 읽는다

**한 줄 요약**: AI가 상세 내용을 읽고 "임창정·손승연 무료 공연"처럼 눈에 띄는 한 줄을 붙인다. 상세 내용에 없는 사실은 쓰지 않는다. 요약에 쓴 출연자·시간은 원문에 글자 그대로 있는지 코드로 대조한다 (블로그 자동화의 원문 대조 방식과 같음).

**스타필드 포스터**: 이미지에서 프로그램명·날짜·시간·대상 연령을 읽는다. 읽은 값도 같은 이미지에서 두 번 읽어 일치할 때만 쓴다 (Claude 판단). 못 읽으면 이벤트 제목과 날짜만 보여 준다.

**동네 묶기**: 1차 동네는 스타필드 수원(화서역 주변 포함), 행궁동(화성행궁·통닭거리·화서문 포함), 광교(광교호수공원 포함), 그 밖은 구 단위(장안·권선·팔달·영통). 장소명·주소·좌표로 정한다. 동네 목록은 설정 파일로 둔다.

**중복**: 같은 행사가 여러 출처에 있으면 하나로 합친다 (제목·기간·장소 비교).

**AI 모델**: 기존 자동화처럼 Gemini 무료 키 또는 Aside 경로를 쓴다. 유료 API는 쓰지 않는다.

## 5. 화면 (사용자 결정: 시안 B안, 태그 없음)

휴대폰 화면 기준 한 페이지.

- 제목: "이번 주 수원, 애랑 갈 만한 곳"
- 동네별 섹션(스타필드 수원 / 행궁동 / 광교 / …). 행사 없는 동네는 숨김
- 행사 카드: 행사명, 날짜·시간, 한 줄 요약. 누르면 원문(시 포털 상세·스타필드 이벤트) 링크로 이동
- 맨 아래 "상시 전시·행사" 묶음
- 마지막 갱신 시각 표시
- 시안 파일: 브레인스토밍 세션의 `area-v2.html`

## 7-1. 검토 후 정한 것 (Claude 판단)

- **주최 예외 범위**: 상세 페이지 "주최기관"에 `수원`(수원시·수원특례시·수원문화재단·구청 등) 또는 `경기`(경기도·경기문화재단·경기아트센터 등)가 들어가고 제목이 축제·페스티벌·페스타·문화제·야행·마켓·장터를 포함하면 예외. 예외는 대상·제목 필터만 무시하고 **기간 필터(이번 주)는 그대로** 적용한다. 상세 페이지는 기간 필터를 통과한 후보만 호출한다
- **경기아트센터·경기문화재단은 1차 필수 아님**: 수집이 막히면 빼고 1차를 내고, 막힌 이유를 보고한다
- **주간 글 선정**: 규칙으로 후보를 고르고(토·일에 걸치는 행사, 주최 예외 축제 우선, 동네별 최대 2개) AI는 한 줄 요약만. 승인 대기는 금요일 12:00까지, 승인 없으면 그 주는 건너뛴다. 확인받는 기간은 3주, 이후 자동 발행 전환은 사용자에게 다시 묻는다. 승인 버튼은 `ai-hub/shared/scripts/notifiers/telegram.py`를 그대로 쓴다 (주간 글 스크립트가 `ai-hub` 안에 있으므로)
- **AI 키**: `suwon-kids`는 Gemini 무료 키만 쓰고 키는 `.gitignore`된 `suwon-kids/.env`에 둔다. `ai-hub` 모듈을 import하지 않는다. 포스터 읽기는 스타필드 이벤트가 한 달 3~5건이라 하루 한도 안에서 충분하다. 이미 읽은 포스터(`img_uri` 같음)는 다시 읽지 않는다
