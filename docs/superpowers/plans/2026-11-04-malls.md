# 백화점·쇼핑몰 아이 행사 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 수원 근처 백화점·쇼핑몰 7곳의 아이 대상 행사를 매일 모아 사이트 '백화점' 탭과 인스타용 `malls.json`에 쓴다.

**Architecture:** 매장 계열별 출처 모듈(롯데·현대·AK·스타필드 브랜드·뉴스)이 `MallItem` 목록을 돌려준다. `suwon_kids/malls.py`가 이것을 모아 기간·지점·아이 대상(규칙 → Gemini, 캐시)으로 거르고 중복을 합친다. `build.run`이 그 결과를 HTML 탭에 넣고 `malls.json`을 쓴다. `events.json`에는 넣지 않는다. 덤으로 `festivals.json`이 매일 돌지 않던 버그를 `deploy.py`에서 고친다.

**Tech Stack:** Python 3.15 표준 라이브러리만(urllib, re, html, json, dataclasses), unittest, 기존 `suwon_kids.http`·`suwon_kids.ai`(Gemini).

**Spec:** `docs/superpowers/specs/2026-11-04-malls-design.md`

## Global Constraints

- 새 의존성 없음. 표준 라이브러리 + 저장소 안 모듈만
- 테스트는 네트워크 없이 돈다. `tests/fixtures/`의 2026-11-04 응답을 읽는다. 실행: `python3 -m unittest discover -s tests -t .`
- 출처 하나가 실패해도 나머지는 계속한다. 이 기능 전체가 실패해도 기존 사이트 빌드·배포는 그대로 나간다
- 백화점 행사는 `events.json`(`site/`, 루트 둘 다)에 넣지 않는다. HTML과 `malls.json`에만
- `malls.json`, `festivals.json`은 git에 올리지 않는다(`deploy.PUBLISHED`에 넣지 않음)
- 행사 포스터·매장 사진을 쓰지 않는다
- 기사에서 뽑은 시작 날짜는 기사 글자에 있어야 한다(`naver.mentions`)
- 매장 7곳 이름·주소 (아래 `mall_info.MALLS` 값 그대로):
  - `타임빌라스 의왕` — `경기도 의왕시 바라산로 1`
  - `타임빌라스 수원` — `경기도 수원시 권선구 세화로 134`
  - `롯데백화점 평촌` — `경기도 안양시 동안구 시민대로 180`
  - `롯데몰 광교` — `경기도 수원시 영통구 이의동 1338`
  - `스타필드 수원` — `경기도 수원시 장안구 수성로 175`
